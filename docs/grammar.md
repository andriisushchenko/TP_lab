# Специфікація мови SIPL

Машинозчитувана граматика: [`src/sipl/grammar/sipl.lark`](../src/sipl/grammar/sipl.lark) (Lark, LALR(1)).

## 1. БНФ (Практикум, ПР 1, с. 8–9)

```
P ::= begin S end                                                       P1
S ::= x := a | S1 ; S2 | if b then S1 else S2 | while b do S
    | begin S end | skip                                                S1–S6
a ::= n | x | a1 + a2 | a1 - a2 | a1 * a2 | (a)                         A1–A6
b ::= a1 = a2 | a1 > a2 | b1 ∨ b2 | ¬ b | (b)                           B1–B5
x ::= ... M | N | ...
n ::= ... -1 | 0 | 1 | 2 | ...
```

Розширення: `div` і `mod` (цілочисельне ділення та остача). Вони потрібні у варіантах ПР 1 (№ 2, 4, 9, 15).

## 2. Лексика

| Лексема | Запис |
|---|---|
| Змінна `x` | `[A-Za-z_][A-Za-z0-9_]*`, крім ключових слів |
| Число `n` | `0`, `1`, `42`; від'ємне: `-1` (мінус лише перед числом) |
| Ключові слова | `begin end if then else while do skip div mod or not` |
| ∨ | `or` або `∨` |
| ¬ | `not` або `¬` |
| Інші символи | `:=  ;  +  -  *  =  >  (  )` |
| Пробіли, переведення рядка | ігноруються |

## 3. Пріоритети (від найслабшого)

1. `;`. За практикумом, цикл має вищий пріоритет, ніж послідовне виконання:
   `while b do S1; S2` = `(while b do S1); S2`.
2. `if` / `while`: гілки та тіло складаються з одного оператора. Кілька операторів беруться в `begin ... end`.
3. `∨` < `¬` < порівняння (`=`, `>`).
4. `+ -` < `* div mod`.

Усі бінарні операції ліво-асоціативні: `a - b - c` = `(a - b) - c`.

## 4. Що НЕ входить до мови (за БНФ)

`<`, `<=`, `<>`, `and`, `true`/`false`, `/`, унарний мінус перед змінною (`-x`), коментарі.
Програма без зовнішнього `begin ... end` некоректна.
